## 三条产品线，差别到底在哪

很多人把这三条线理解成“低配、中配、高配”，其实不是。它们解决的是三个不同的问题。

**三网直连 CMI/CU2/CN2** 走的是大陆方向优化。官方写得很具体：电信去程 CN2 精品线路直连不绕路，联通去程 9929 精品线路，移动去程 CMIN2，三网回程走大陆优化线路，标称中国大陆三网平均延迟 50ms 左右。IP 是香港原生 IP，官方点名可解锁 Netflix、Disney+、YouTube Premium、Amazon Prime Video、Spotify、Steam、HBO。这条线面向的就是“大陆用户访问要快”这件事。

**iCable 双 ISP 住宅 IP** 的重点不在速度，而在 IP 是谁的。IP 来自香港有线宽屏（本地宽带运营商），数据库里显示的是住宅家宽属性，官方明确写可看 TVB、支持 Cityline 票务。但同一段官方描述里还有一句很关键的话：**非大陆直连优化网络，建议通过香港或日本线路中转使用，建议开启 BBR 加速**。它同时提到部分地区电信和移动直连速度不错，也就是说能不能直连看你所在运营商，不保证。

**HGC 双 ISP 住宅 IP** 同样是住宅属性，IP 来自和记电讯，但官方给它的定位是“三网优化线路”。这是它和 iCable 最大的区别：两者都是香港本地宽带运营商的住宅 IP，HGC 在大陆方向的优化做得更明确一些，起步价也更高，99 元/月对 88 元/月。

为了讲清楚这三条线的取舍，先分清三种 IP：

- **数据中心 IP**：机房里分配出来的 IP，最便宜，平台识别率高，Netflix 这类服务经常直接拒绝。
- **原生 IP**：归属地确实是香港的真实 IP，注册地和使用地一致，港区流媒体打开成功率明显更高。
- **住宅 IP / 双 ISP IP**：来自本地宽带运营商的 IP 段，纯净度比机房 IP 高一档，TVB 直播、Cityline 购票这类对 IP 属性敏感的本土服务能正常访问。

住宅 IP 不是万能的，解锁能力会随平台风控规则变化，这是整个行业的共性，不是某一家的问题。但如果你的用途本身就是港区流媒体和本地服务，机房 IP 基本没有讨论余地。

**iCable 和 HGC 都是住宅 IP，选哪个？**
